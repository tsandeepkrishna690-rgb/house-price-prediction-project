# 🏠 House Price Prediction

## 📌 Project Overview

House price prediction is an important real-world problem. This project uses Machine Learning to predict house prices based on house-related features such as living area, overall quality, and year built.

## 🎯 Objective

The objective of this project is to build a Machine Learning regression model that predicts house prices based on different property features.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 📂 Dataset Features

The project uses house information such as:

- Overall Quality
- Living Area
- Year Built
- Total Basement Area
- Garage Cars
- Number of Bedrooms
- Lot Area

### Target Variable

**SalePrice**

The target variable represents the selling price of the house.

## 🤖 Machine Learning Models

- Linear Regression
- Random Forest Regressor

## 📊 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
- Actual vs Predicted Price Visualization

## 🚀 Project Outcome

The trained model predicts house prices using property features. Model performance is measured using regression evaluation metrics.
